# Cynthia Curriculum

一张根据温州肯恩大学 2026 秋季课表整理的交互式周课表。

## 功能

- 按真实上课时长展示不同高度的课程块
- 点击课程查看教师、地点、时间和学分
- 支持全部课程、美方课表和温州课表筛选
- 适配桌面端与移动端

## 技术栈

- React 19
- TypeScript
- Vinext / Vite
- CSS

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```
